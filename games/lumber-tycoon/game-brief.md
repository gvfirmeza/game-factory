# Game Brief: Lumber Tycoon

## Core Concept
A complete, polished, mobile-friendly **3D Lumber Tycoon** game. Players chop trees, collect logs, carry them to a selling platform, earn cash, purchase upgrades, hire NPC workers, and unlock new forest zones—progressing from a lone lumberjack to operating a fully automated lumber business.

## Core Gameplay Loop
**Chop → Collect → Carry → Sell → Upgrade → Unlock → Automate → Repeat**

## Key Features

### Player Actions
- Chop trees by interacting (tap/click) until they fall
- Collect fallen logs automatically or manually
- Carry logs physically back to the base
- Stand on selling platform to sell carried wood for cash

### Progression System
- Better axes (faster chopping, higher yield)
- Larger carrying capacity
- Faster movement speed
- Unlockable forest zones with better trees
- Better selling prices
- Automated wood-processing upgrades
- Hireable NPC lumberjack workers

### NPC Workers
- Hire lumberjack NPCs that autonomously:
  - Find available trees
  - Walk to them
  - Chop them automatically
  - Carry wood back to base
  - Deposit/sell the wood
- Higher-level workers = faster and more efficient

### World
- Forest area with different tree types and sizes
- Player base with selling platform
- Upgrade shop
- Worker hiring area
- Multiple unlockable forest zones
- Visual progression between areas

### Feel & Presentation
- Smooth character animations
- Tree falling animations
- Wood pickup effects
- Coins/cash popups with floating numbers
- Simple particles
- Sound effects
- Clear visual feedback for every interaction
- Clean, colorful, stylized low-poly 3D aesthetic

### UI
- Current cash
- Wood carried / capacity
- Current axe tier
- Upgrade buttons
- Worker count
- Area unlocks
- Interaction prompts
- Non-intrusive design

### Quality Requirements
- Smooth mobile controls
- Responsive interactions
- Proper collision detection
- Working NPC pathfinding
- Save/load progression
- Tutorial/onboarding
- Pause/settings
- Balanced economy
- No placeholder mechanics
- Good mobile performance
