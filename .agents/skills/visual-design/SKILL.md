# Visual Design Skill

## 1. Aesthetic Identity
- **Tone**: Cute, joyful, vibrant, soft-shaded 2D vector style.
- **Silhouette**: Bold, rounded shapes with subtle dark-colored outlines (not harsh black, e.g. `#2C3E50` or `#1E293B`).
- **Depth**: Subtle soft drop shadows (`rgba(0, 0, 0, 0.15)`) under characters and vehicles to ground them in the scene.

## 2. Color Palette Presets
- **Nature / Pasture**: Grass (`#6BCB77`), Dark Grass (`#4D96FF`), Dirt/Path (`#F7D070`), Water (`#4D96FF`).
- **Asphalt / City**: Road (`#34495E`), Markings (`#F1C40F`, `#ECF0F1`), Sidewalk (`#BDC3C7`).
- **Character Colors**: Warm Yellow (`#FFD93D`), Fox Orange (`#FF6B6B`, `#FF8E53`), Mint Green (`#6BCB77`), Berry Purple (`#9B59B6`).
- **Hazards & Warnings**: Vibrant Coral (`#FF4757`), Sunset Orange (`#FFA502`), Crimson Alert (`#ED4C67`).

## 3. UI & Readability
- HUD elements must maintain minimum 4.5:1 contrast ratio against gameplay backgrounds.
- Text uses rounded, modern fonts (e.g. `'Fredoka', 'Nunito', 'Segoe UI', system-ui, sans-serif`).
- High-visibility score displays with subtle white/black stroke or backing pill.
